# 検証結果

## 日本語を含むJSONの受信修正（2026-11-26）

Azure CLIがCP932で出力したJSONをUTF-8として受け取ると、日本語タグの一部が不正な逆斜線エスケープとなり、`tags.cost_center`で読込みが止まることを再現しました。ユーザー端末の文字コードそのものを測定した結果ではありません。

CSV作成の一覧取得、移行のサブスクリプション一覧取得、テスト用リソース作成のサブスクリプション情報取得の3か所を修正しました。日本語をエスケープしたJSON文字列で受け取り、読込み時に元の値へ戻します。取得先・条件分岐・命名規則・保存先の設定値は変更していません。

|確認|結果|
|---|---|
|旧版の不具合再現|実Azure CLIのCP932出力をPowerShell 7.5.4で受け取り、同じ不正エスケープを確認|
|CSV作成の回帰試験|7シナリオ・54判定成功。日本語・引用符・逆斜線・改行・絵文字の値を保持|
|移行の回帰試験|91ケース・1,341判定成功|
|Azure応答での確認|日本語タグ付きの空リソースグループを読み、旧版のエラーと修正版の値保持を確認|
|後片付け|作成した空リソースグループは削除済み。開始前と同じRG0件を確認。課金対象のリソースは作成していない|

確認基盤はLinuxのPowerShell 7.5.4・Azure CLI 2.93.0です。実Windows OSでの実行は未実施ですが、同じ文字コードの組み合わせを再現して確認しています。[再現・実行結果・コードのSHA](JSON_ENCODING_FIX.json)を保存しています。

## コメントの確認（JSON受信修正前）

処理の大きな段階だけをブロックコメントにし、step1の番号をREADMEの5段階にそろえました。補足は通常のコメントにし、用語集は作らず、必要な意味を関数ヘルプや処理の説明に書いています。

操作用スクリプト8本の構文と、コメント以外のトークン・文の区切りが変更前と同じことを確認しました。9関数・26引数のヘルプ表示、学習資料の28範囲・54検索語と説明へのリンクも確認しています。Azureへの通信は行っていません。

下の91ケース・52判定の試験は、コメント変更前の記録です。実行コードと設定値が同じため再実行はしていません。過去の試験時のSHAは書き換えず、現在のSHAと比較結果を[出荷確認のCommentReview](RELEASE_CHECKS.json)に追加しています。

## CSV作成のAzure実機試験（2026-11-26）

検証用の2サブスクリプションで、フォルダ整理前の`tools/create_targets.ps1`を実行しました。PowerShell 7.5.4・Azure CLI 2.93.0を使い、応答の置き換えは行っていません。出荷版で変わったのは既定出力先のパスだけで、環境の検索とCSVの生成処理は同じです。

|ケース|確認した動作|結果|
|---|---|---|
|CSV-LIVE-001|本番の直下・子管理グループから2サブスクリプションを取得。略称がない行はプレースホルダーにする|PASS|
|CSV-LIVE-002|検証の対象だけを取得し、大文字の略称から小文字の保存先名を作る|PASS|
|CSV-LIVE-003|開発はsandbox配下を取得し、名前とCSVにはdevを使う|PASS|
|CSV-LIVE-004|alert用グループが2つある場合、略称を勝手に選ばずプレースホルダーにする|PASS|
|CSV-LIVE-005|対象サブスクリプションが0件なら、6列の見出しだけを出力する|PASS|
|CSV-LIVE-006|24文字のストレージ名を生成し、文字数の警告を出さない|PASS|
|CSV-LIVE-007|25文字の生成名は勝手に短縮せず、警告する|PASS|
|CSV-LIVE-008|jpeを2か所含む生成名を警告する|PASS|
|CSV-LIVE-009|管理グループの取得に失敗したらエラーで終了し、既存CSVを上書きしない|PASS|

各実行で、他環境CSVのSHAと更新日時が変わらないことも比較しました。出力した8ファイルの全セル・見出し・BOM・保存SHAを別途確認しています。実機ではページングは発生していません。次ページの取得と取得失敗は、後述のローカル試験で確認しています。

準備では、作成済みの管理グループが一覧に現れず停止したため、検証準備側を直接GETで確認する方法へ修正し、一度削除して準備し直しました。この段階ではCSVスクリプトは未実行で、配布コードの修正もありません。

作成したのは管理グループと空のリソースグループだけです。課金対象のリソースは作成していません。試験後は両サブスクリプションを元の所属へ戻し、今回作成したグループをすべて削除しました。[実行結果・コードのSHA・後片付けの確認](CSV_GENERATOR_AZURE.json)を保存しています。
