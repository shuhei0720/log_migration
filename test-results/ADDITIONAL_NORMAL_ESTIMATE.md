# 追加の正常通しテスト：構成と費用

この資料は、追加の正常通しテストを承認する際の構成案と計画見積を残したものです。全タイプ案の環境作成と移行4工程は実施済みで、移行は成功しました。実行結果・実測時間・撤去状況は[検証結果](REPORT.md)を参照してください。

**全タイプ案・総額10,000円の計画予算（従来6,000円から追加4,000円）が了承されました。** 前の試験資源を撤去した後、解除待ちだったBのNetwork・Computeの2件だけは、了承を得て最終復元へ持ち越し、再登録して追加試験を進めました。元の未登録状態の証明と旧待機記録は保持しています。下表の代表構成案は未選択の比較案です。

| 項目 | 元の全タイプを作り直す案 | 代表構成を作り直す案 |
|---|---|---|
| 新しい環境 | 依頼された新規50型、補助を含む実53型・基本65root。負荷NSG300個は重複作成しない | 基本15root：VM2・VMSS2・旧DCR2＋対象外DCR・LAW・Storage・NIC・NSG |
| 配置 | 2Sub・4地域 | 2Sub・3地域。全50型・4地域の再作成は省略 |
| 確認すること | 各タイプと既知の子scopeを含め、確定版で作成から移行・撤去まで確認 | 共通の移行処理を実在の代表資源で確認。全タイプの作り直し確認にはならない |
| 新環境の全寿命 | 2～3時間を計画。作成・待機・移行・削除完了を含む | 同じく2～3時間を計画 |
| 追加正常テストの見積 | **約3,090～3,693円** | **約1,273～1,351円** |
| 現行試験6,000円枠と合わせた見積 | 約9,090～9,693円 | 約7,273～7,351円 |
| 全体計画予算 | **10,000円（承認済み）** | 8,000円（未選択の比較案） |

見積もりでは、必要RPの登録、検証用VNet・固定サブネット、新Windows・結果回収用保存先の準備を想定しました。配布するfixture自体は既存VNetのリソースIDを参照します。表の2～3時間とWindows準備0.5時間は計画値で、実測値ではありません。未確定費用・小容量データの予備1,000円、10%税予備を含み、全タイプ案にはNATログ月額・SQL/ACR日額等の最低課金も確保した見積もりです。

実行順は、環境作成→旧設定の準備→事前確認→複製→照合→旧設定削除→保存先・新設定の最終照合→全撤去・元状態確認です。ログの実着信を待つ試験は行っていません。全タイプ案をAzureで実行し、固定した正本で移行4工程を各1回実行して成功しました。App Serviceは配置制約に合わせ、移行開始前にLinux S1からP0v3へ変更しています。環境配置時の失敗・変更履歴は検証結果に保存しており、移行4工程の成功とは分けています。

全タイプ案でも、Code Signing・Bing・ExpressRoute・Databricks・旧Redisは、契約・退役・既存ネットワーク条件等による既存の省略を維持します。代表案への縮小を、全タイプ案の成功と置き換えません。

当初参照した2026年11月25日00:23 UTCの税前2,151.05円は、過去の取得時点の反映額です。最新の実コストは[検証結果](REPORT.md)に、取得履歴と正確な小数値・条件は[evidence.json](evidence.json)の`actualCost`（最新は`latest`）に記録しています。請求データの反映完了は確認できず、最終実費・残予算は未確定です。前回11月19日分2,287.39円は今回の計画から分離しています。上表はRetail単価と予備による計画見積で、実請求額ではありません。
